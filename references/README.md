# Referencje źródłowe (otwieraj wybiórczo)

Pliki są materiałami pomocniczymi do wygenerowania prototypu. **Nie są źródłem prawdziwych cen, stref dostawy, danych kontaktowych ani danych osobowych dostawców.**

| Plik | Rola | Kiedy otworzyć |
| --- | --- | --- |
| `logo.png` | Oryginalny znak graficzny | Tworzenie nawigacji/stopki |
| `wyglad-strony.png` | Najważniejsza referencja wizualna | Etap E1: UI |
| `uklad-strony.png` | Wcześniejsza makieta lo-fi | Tylko gdy potrzebna historia zmian |
| `architektura-tresci.png` | Priorytety i kolejność sekcji | Rozstrzyganie IA |
| `prezentacja-dla-klienta.png` | Uzasadnienie decyzji | Dokumentowanie UX |
| `persona1.png`, `persona2.png` | Projektowa persona Tomasza | UX/copy, nie publiczna karta klienta |
| `user-stories.png` | Zebrane potrzeby użytkownika | Audyt przepływów |
| `brief.pdf` | Brief #8, strony 2–3 | Weryfikacja faktów |
| `wiadomosc-do-klienta.pdf` | Przyjęte decyzje UX | Konflikty wymagań |
| `persona-heurystyki-makieta.pdf`, `zajecia-1.pdf` | Materiały metodyczne z zajęć | Opcjonalnie przy uzasadnieniu i prezentacji |

Uwaga: oryginalna kolorowa makieta i niektóre dokumenty mają wcześniejszy zapis marki. **Obowiązuje wyłącznie `wuzwarzyw`.** Nie wycinaj fotografii bezpośrednio ze screena i nie przedstawiaj ilustracyjnych profili jako zweryfikowanych prawdziwych rolników.
